# HACKATHON 2026 Quiz Portal

GitHub Pages-ready qualifying assessment frontend.

Sections: Aptitude 30, General Computer Knowledge 20, Logical & Reasoning 25, Coding Snippets 25. Total 100 questions, 100 marks, 90 minutes.

Replace the sample/placeholder questions in `questions.js` with the official question bank before publishing the real test.

Current version is frontend-only: scoring occurs in the browser. Backend submission/results integration can be added next.
